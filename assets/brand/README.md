# Marpres identity

The folded M retains the original draft's page/screen motif. The production mark uses two flat vector paths with consistent corner treatment and an open central gap for small-size legibility.

| Files | Use |
| --- | --- |
| `marpres-mark.svg` / `.png` | Symbol only, navy on transparent background |
| `marpres-wordmark.svg` / `.png` | Horizontal symbol + Marpres wordmark |
| `*-light.svg` | White artwork for dark backgrounds |
| `marpres-app.svg` / `.png` | Symbol on a rounded white application-icon tile |
| `marpres-app-wordmark.svg` / `.png` | Application icon with the wordmark underneath |
| `marpres.icns` / `marpres-wordmark.icns` | macOS icons, 16–1024px representations |
| `marpres.ico` / `marpres-wordmark.ico` | Windows/web icons, 16–256px representations |

Use the symbol-only application icon at small sizes. Prefer SVG for slides and web content; the PNG exports are transparent artwork or app tiles as indicated above. Keep proportions intact and leave clear space around the mark. The main ink colour is `#101828`.

## Typography and licence

The wordmark uses **Outfit, weight 650**, converted to SVG outlines. No installed font or external font request is needed to display the artwork. The raster draft did not establish its original typeface or licence; the production wordmark uses this verified replacement.

Outfit is distributed under the **SIL Open Font License 1.1**, which permits commercial use and creating logos. See the [upstream licence](https://github.com/google/fonts/blob/main/ofl/outfit/OFL.txt) and [OFL FAQ 1.1](https://openfontlicense.org/ofl-faq/#faq1_1). A copy is included as `OFL-Outfit.txt`. The complete font software is not bundled here.

## Design provenance

The supplied raster draft was refined with the built-in image-generation tool, then recreated as clean SVG geometry. The refinement prompt preserved the folded two-panel M, navy colour and rounded corners, and requested balanced proportions, a wider internal gap, flat silhouettes, transparency, and no added decorative elements. The final wordmark was independently typeset using the verified font above; it was not traced from the raster lettering.

These SVGs are the editable production sources. Generated icon sizes come from the corresponding application-icon SVG; both icon containers include multiple resolutions.
