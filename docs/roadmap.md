# Presenter tools roadmap

Marpres currently has single-window Play with cumulative reveals. The following presenter tools are planned for a later release; they are not implemented in the current editor.

- **Dual-screen presentation:** a clean audience window for the second display and a separate presenter window with a smaller current-slide preview and navigation.
- **Presenter notes:** notes stored with the Markdown source, visible to the presenter and hidden from audience output.
- **Synchronized navigation:** keep both windows on the same slide and reveal stage.
- **Pointer tools:** an ordinary pointer, laser pointer, and spotlight-style highlight.
- **Whiteboard and annotations:** drawing tools for live explanations, with a clear choice of how annotations persist or clear between slides.

The presenter workflow should preserve the existing Markdown source, cumulative reveals, and clean exports. Fullscreen behavior, opening the audience window, and annotation lifetime will be defined as part of that work. No release date is committed.
